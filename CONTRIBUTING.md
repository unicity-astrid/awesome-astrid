# Contributing to Awesome Astrid

Thank you for helping grow the Astrid community! This document explains how to add or update entries in this list.

## Before You Submit

- **Search first.** Check that your project is not already listed.
- **Your project must be related to Astrid OS.** It should be a capsule, SDK, distro, tool, or resource that builds on or extends Astrid.
- **Quality over quantity.** Only submit projects that are useful, tested, and maintained. Unmaintained projects will be removed.

## What to Submit

| Category | What belongs here |
|---|---|
| **Community Capsules** | Third-party capsules: tools, providers, orchestrators, uplinks, interceptors |
| **SDKs & Libraries** | Language SDKs, client libraries, helper crates/packages for capsule authors |
| **Distros & Configurations** | `config.toml` + capsule bundles targeting specific use cases |
| **Tools & Utilities** | Build tools, CLIs, dev utilities for working with Astrid capsules |
| **Documentation & Tutorials** | Guides, blog posts, videos explaining Astrid concepts or capsule authoring |

## Format

Each entry should follow this format:

```markdown
- [project-name](https://link-to-repo-or-page) - Short description starting with a capital letter and ending with a period.
```

Keep descriptions short (one sentence), factual, and written in the same style as existing entries.

## How to Submit

1. **Fork** this repository.
2. **Edit** `README.md` — add your entry in alphabetical order within the correct category.
3. **Open a Pull Request** with a clear title such as `Add capsule-my-tool to Community Capsules`.
4. A maintainer will review your PR. Be prepared to iterate based on feedback.

## Removing Entries

If a project is abandoned, broken, or no longer relevant, open an issue or PR to remove it. Include a brief reason.

## Code of Conduct

Be respectful. This list exists to help the community. Constructive feedback is welcome; harassment is not.
